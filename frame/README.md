# 机架尺寸说明（Whoop-65B）

本目录给出 **65 mm 桨尖距** Whoop 机架的关键尺寸，便于：

1. 采购时核对「是不是 65 mm 架」；  
2. 用 CAD / 3D 打印自制涵道与底板（简易参数化，非精密宇航件）。

优先建议：**直接购买现成 65 mm Tiny Whoop 塑料架**，尺寸公差与韧性通常优于首次打印件。

## 1. 定义

| 术语 | 含义 |
|------|------|
| 桨尖距 / 轴距相关 | 本设计以**相对电机轴中心的对角线距离 ≈ 65 mm** 的 Whoop 级机架为准（商家常标「65 mm」） |
| 电机中心正方形边长 | 约 **46 mm**（√2 关系：对角线 65 mm 时边长 ≈ 65/√2 ≈ 46 mm） |
| 涵道内径 | 略大于桨盘；31 mm 桨建议内径 **≥ 33 mm**，径向间隙约 1 mm 级 |
| 整机外廓 | 约 **70 × 70 × 20–28 mm**（含上盖） |

```
俯视示意（单位 mm，名义值）：

        前
    M4 ---- M2
    |  ~46  |
    |       |
    M3 ---- M1
        后

对角线 M4–M1 或 M2–M3 ≈ 65
```

## 2. 关键尺寸表（打印 / 核对用）

| 参数 | 名义值 | 公差建议 | 说明 |
|------|--------|----------|------|
| 电机轴距（相邻） | 46 mm | ±0.5 mm | 正方形布局 |
| 电机轴距（对角） | 65 mm | ±0.7 mm | 与「65 mm」标称一致 |
| 716 电机仓内径 | ≈ 7.1–7.3 mm | 过盈或卡扣按材料调 | 8520 则按 8.5 mm 级开孔 |
| 电机仓深度 | ≥ 10 mm（716） | — | 以电机长度为限 |
| 涵道高度 | 12–18 mm | — | 过高增重，过低护桨差 |
| 桨盘名义 | 31 mm | — | 与 [bom.md](../bom.md) 一致 |
| 涵道内径 | 33–34 mm | — | 避免刮桨 |
| AIO 安装孔 | 按所购 AIO | — | 常见微型孔距，打印前量板子 |
| 中心平台厚度 | 1.0–1.5 mm | — | PETG 可略薄；脆树脂加筋 |
| 电池舱（下部） | 约 20×12×8 mm 空间 | — | 容 1S 300–450 mAh |

## 3. 3D 打印建议

| 项目 | 建议 |
|------|------|
| 材料 | **PETG** 或韧性树脂；PLA 易摔裂，仅作外形验证 |
| 层高 | 0.16–0.2 mm |
| 填充 | 涵道壁 20–30%；臂可加周壁厚度 |
| 方向 | 涵道开口朝上打印，减少支撑刮擦面 |
| 后处理 | 修掉支撑；电机孔用铰刀轻轻修到不松不转 |

打印件若比注塑架重 1–2 g，需从电池容量或电机规格上找回推重比（见 [specs.md](../specs.md)）。

## 4. 简易模型参数（自行建模）

### 4.1 MacBook Pro + Blender（推荐快速出 `.blend`）

1. 从 [blender.org](https://www.blender.org/download/) 安装 Blender（Apple Silicon 选 macOS ARM）。  
2. 打开 Blender → 顶部菜单 **Scripting** → **Open** 打开本目录 [`whoop65b_blender.py`](whoop65b_blender.py)。  
3. 点 **Run Script**：生成 Whoop-65B 机架（底板 + 四涵道 + 电机孔 + 电池槽）。  
4. **File → Save As** 存为 `Whoop65B_Frame.blend`；需要打印再 **Export → STL**。  
5. 出设计图：场景里选相机 `Whoop65B_Top`（俯视）或 `Whoop65B_Iso`（轴测）→ `F12` 渲染。

也可用终端（把路径换成你的仓库位置）：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python /path/to/mini-drone-65mm/frame/whoop65b_blender.py
```

用 Fusion 360 / FreeCAD / OpenSCAD 时可按下列布尔思路：

1. 底板：70×70×1.2 mm 圆角矩形（或十字臂）。  
2. 四角：电机孔，中心落在边长 46 mm 正方形顶点。  
3. 每角圆柱涵道：内径 33.5 mm，壁厚 0.8–1.2 mm，高 15 mm。  
4. 中心沉台：按 AIO 外形开孔 + 4 个安装孔。  
5. 底部电池槽：凹槽 + 扎带孔。

本仓库**不附带现成 STL 二进制**（避免与商业机架版权冲突）；按上表建模即可得到可打样几何。若你使用开源 Whoop 架 STL，请遵守其许可证并核对角线是否为 65 mm。

## 5. 与现成机架的兼容

购买时认准：

- 标题含 **65 mm** / **65mm whoop**；  
- 配 **31 mm** 桨；  
- 电机位为 **716 或 8520**；  
- 中心可安装你的 **有刷 AIO**（看评测照片孔位）。

买到 75 mm / 85 mm 架时，本 BOM 的桨与手感不再适用，需整套改规格。
