# Whoop-65B — 65 mm 迷你无人机可试做设计

室内向 **Tiny Whoop** 级四轴：桨尖距约 65 mm，起飞重量约 25–35 g，1S 有刷动力 + Betaflight。按本文档可采购零件、焊接组装并完成系绳悬停。

## 这不是苍蝇级飞行器

| | 苍蝇 / 实验室昆虫机器人 | 本设计 Whoop-65B |
|--|-------------------------|------------------|
| 尺度 | 毫米级 | **厘米级（~7 cm）** |
| 重量 | 毫克–百毫克 | **约 25–35 g** |
| 动力 | 扑翼 / 磁驱等 | **有刷电机 + 螺旋桨** |
| 可得性 | 实验室为主 | **淘宝级零件可组** |

若你需要真正「苍蝇大小」方案，那是另一条技术路线，不在本仓库范围。

## 快速路径

1. 按 [bom.md](bom.md) 下单（推荐「轻量室内档」）。  
2. 按 [assembly.md](assembly.md) 无桨焊接并检查。  
3. 按 [betaflight.md](betaflight.md) 刷机、绑定、Failsafe。  
4. 装桨 → **系绳悬停** → 再自由飞。  

## 安全摘要

- 桨叶与 LiPo 均有伤害/起火风险；护罩不拆除、充电器要用对、失控保护必须测。  
- 仅限合规空域与场所；室内注意他人与宠物。  
- 本设计供学习与娱乐组装，不提供飞行器适航认证。

## 成功标准（自检）

- [ ] 能按 BOM 买齐兼容零件  
- [ ] 能组装为完整带涵道四轴  
- [ ] Betaflight 可解锁且电机顺序/转向正确  
- [ ] 完成至少一次系绳悬停  

## 明确不做

- 苍蝇级 / 扑翼 / 磁驱  
- 自研飞控固件或手机飞控 App  
- 标配高清图传（可选扩展见 BOM）
